---

🎯 **Nó làm được gì?**

• Paste cả list code vào → extension tự bấm nút "Đổi" cho từng cái
• Delay giữa các code tự chỉnh (mặc định 2s, sợ ban thì kéo lên 5s)
• Tự retry khi lỗi mạng, tự tạm dừng nếu server Garena đang ảo
• Ghi log chi tiết: cái nào ok, cái nào fail, cái nào do server lỗi
• Xuất lịch sử ra CSV để lưu lại xem

1. **Trước khi đăng:**
   - Vào group, check rule group. Nhiều group cấm đăng link bên ngoài lần đầu — lúc đó bỏ 2 link GitHub, chỉ để link Chrome Web Store.
   - Nếu group yêu cầu tag admin / xin phép trước → nhắn tin admin hỏi.

2. **Giờ đăng tốt nhất:**
   - **12h-13h30** (anh em nghỉ trưa lướt FB)
   - **20h-22h** (giờ vàng game thủ)
   - **Thứ 6, thứ 7, chủ nhật** engagement cao nhất

3. **Sau khi đăng:**
   - Reply **mọi comment trong 2 giờ đầu** — thuật toán FB đẩy bài có reply nhanh
   - Pin comment câu hỏi thường gặp: *"Có bị khóa acc không?"* → không + hướng dẫn
   - Nếu bài được share nhiều → cập nhật thêm code mới ngay để giữ tương tác

   - Tránh từ: "tool", "hack", "cheat" — dù dùng đúng nghĩa cũng dễ bị filter
